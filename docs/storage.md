# 显卡小屏幕：存储维护与开机动画

入口：GpuLcd.exe → 存储 / 开机 → 打开存储维护。
也可以运行 GpuLcd.exe --storage。直接启动小工具始终打开完整主界面；维护锁存在时原控制页面可查看，但设备操作暂时禁用。维护窗口可点击“返回主界面”，不会因此解除设备维护锁。

## 已实测（2026-10-06）
- 显卡：GeForce RTX 3070 Ti，LCD 固件版本 122；普通 USB 标识 0C45:9830，COM4。
- 通过厂家库已经打开的 USB 串口发送 F6 5A D0 00 00，保持连接等待 5 秒，成功进入 USB 大容量存储模式。
- Windows 设备：SONiX USB MSC，USB 0C45:6480，序列号 100000000000，磁盘大小 257949696 字节。本次分配 D:。工具每次重新按设备身份识别，不固定使用 D:。
- 先前直接开串口后立即关闭、以及改走 I2C 均未成功。关闭过早是串口失败的推测原因，没有单独实验隔离全部变量。
- 根目录四个启动资源：op.savi / oploop.savi / op1.savi / op1loop.savi。
- 普通动画位于 mov/；字体、背景及配置资源位于 cof/。
- 当前读取到 OpeningMode=0。固件启动时按 0/1 选择 op.savi / op1.savi。
- 4: 是固件文件系统的逻辑卷前缀；这些启动文件实际出现在同一个 USB 磁盘根目录，先前“独立存储区”的说法不准确。
- 初始文件级备份共 34 个文件、81077888 字节，全部逐文件 SHA-256 与设备源文件一致。
- 物理磁盘镜像因 Windows 拒绝原始磁盘读取而未创建。文件备份不等于可直接克隆的磁盘镜像。
- 本次没有替换设备内任何启动资源，没有刷写固件。Windows 挂载可能维护自己的 System Volume Information 元数据。

## 如何使用
1. 存储维护窗口里可以打开屏幕文件夹、备份全部屏幕内容、查看四个启动文件首帧。
2. 默认 op.savi 是方案 0 的启动资源；oploop.savi 是其后续循环资源。每次只替换下拉框选中的一个文件。
3. 选择图片/动画替换会先转换成 480×128 的 SAVI、显示首帧，点击确认后写入。普通 PNG/GIF/MP4 不能直接改扩展名冒充 SAVI。
4. 替换时先把原文件和新文件复制到电脑并校验，再在屏幕盘暂存新文件、改名切换、再次校验。发生错误会尝试还原旧文件。
5. 从备份恢复使用相同流程，选择该文件的原件即可。未完成替换遗留 lcdnew.tmp/lcdold.tmp 时会停止，避免覆盖恢复线索。
6. 完成后关闭资源管理器窗口，使用 Windows 安全删除硬件；再关机、关闭电源开关约 30 秒后开机。
7. 再开小工具，点击“检查并恢复普通控制”。只有设置读取和串口连接都成功才解除维护锁，恢复普通窗口及 助手B 外部指令。
